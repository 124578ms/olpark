# 올팍 언제 갈까

올림픽공원이 언제 붐비는지 시간대별로 알려 주는 웹사이트입니다. 2025년 올림픽공원 입출차 기록 241만 건으로 요일·시각별 주차 기준표를 만들고, 공연 영향과 실시간 주차·인구·날씨를 함께 보여 줍니다.

2026 한국체육산업개발 공공데이터 활용 경진대회 출품작입니다.

## 사용한 공공데이터

| 데이터 | 제공 | 쓰임 |
|---|---|---|
| 올림픽공원 입출차정보(전체구역) | 한국체육산업개발 (문화공공데이터광장) | 시간대별 주차 대수, 출입문 비율 |
| 올림픽공원 차량입출차·공연·날씨 연계 데이터 | 한국체육산업개발 (문화공공데이터광장) | 2025년 공연 시간대와 관람객 수 |
| 올림픽공원 실시간 주차현황 | 한국체육산업개발 | 지금 동2·남2·북2문 주차 대수 |
| 올림픽공원 공연/행사 일정안내 | 한국체육산업개발 (홈페이지 월별 목록) | 2주 안의 공연과 시작 시각, 2025년 공연 시작 시각(시작 기준 영향 계산) |
| 실시간 도시데이터 (올림픽공원) | 서울특별시 | 지금 공원 안 인구와 혼잡도 |
| 단기예보 조회서비스 | 기상청 | 시간별 기온·하늘·강수확률, 비·눈 예보 시각 |
| 중기예보 조회서비스 | 기상청 | 4–10일 뒤 오전·오후 강수확률·날씨, 최저·최고기온 |
| 지상(종관, ASOS) 시간자료 | 기상청 | 2025년 서울 시간 강수량 → 비 온 시간대 주차 감소율 |
| 특일 정보 | 한국천문연구원 | 공휴일 날짜, 2025년 공휴일 주차 감소율(설날·추석 -69%, 그 밖 공휴일 -26%) |

## 구조

```
scripts/fetch_d04.py         입출차 원본 수집 (API_CPM_008)
scripts/fetch_d05.py         공연 연계 데이터 수집 (API_CPM_009)
scripts/aggregate_hourly.py  원본 → data/hourly.csv (시간별 입차·재차대수·공연)
scripts/fetch_asos.py        기상청 ASOS 서울 2025년 시간자료 → data/asos_2025.csv
scripts/build_site_data.py   hourly.csv + asos_2025.csv → web/public/data/site.json (기준표·등급·공연 영향·비 영향)
scripts/fetch_live.py        실시간 주차·인구·날씨·공연 일정 → web/public/data/live.json
web/                         React + Vite + Tailwind 정적 사이트
.github/workflows/deploy.yml 30분마다 실시간 데이터를 받아 GitHub Pages에 배포
```

## 로컬 실행

```
cd web
npm install
npm run dev
```

실시간 데이터를 받으려면 루트 `.env`에 `KMA_KEY`, `SEOUL_KEY`를 넣고 `python scripts/fetch_live.py`를 실행합니다. 키가 없어도 사이트는 기준표 예보만으로 동작합니다.

## 원본 데이터에 대해

입출차정보(전체구역) 원본은 8·9·11·12월이 월 65,534건에서 잘려 있고 매달 말일 기록이 없습니다. 8·9월은 주차 대수 계산에서 빼고 출입문 비율에만 썼습니다. 자세한 처리는 `scripts/build_site_data.py`에 있습니다.
